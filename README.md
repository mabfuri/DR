# DollarRise (DR)

Dashboard platform dengan sistem user Free, Basic, Premium, dan VIP.

## Stack

- React + Vite
- Cloudflare Pages / Workers
- Supabase PostgreSQL + Auth
- Adsterra API

## Status

Project foundation — implementation in progress.

## Planned modules

- Authentication
- User dashboard
- Admin dashboard
- Rolling offers
- Unlock limits
- Premium/VIP rewards
- Balance and transaction history
- Adsterra statistics
